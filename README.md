# Рассадка

Головоломка без текста для телефона: в двухэтажном вагоне шесть мест, пассажиров перетаскивают пальцем, пока все не останутся довольны. Чего хочет пассажир, видно по значку над головой.

Vue 3 + JavaScript + Vite + Pinia + SCSS (БЭМ). Правила кода, структуры и стилей — те же, что во фронтенде проекта хакатона (`docs/frontend`): только `<script setup>`, модели в JSDoc, слои `pages → components → composables → core`, токены в `vars.scss`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

## Перед коммитом

```bash
npm run format   # Prettier
npm run lint     # ESLint, 0 ошибок
npm test         # Vitest
npm run build    # сборка без предупреждений Sass
```

## Где что лежит

| Папка                      | Что внутри                                                               |
| -------------------------- | ------------------------------------------------------------------------ |
| `src/core/data/`           | пассажиры, желания, станции, геометрия вагона                            |
| `src/core/utils/`          | чистые функции: проверка желаний, обмен местами, поиск места под пальцем |
| `src/core/stores/`         | `progress` — номер станции, хранится в `localStorage`                    |
| `src/composables/`         | `useSeating` — ход станции, `usePointerDrag` — перетаскивание            |
| `src/components/Carriage/` | вагон: фон, места, пассажиры, значки желаний, шапка со счётчиком станций |

Новая станция — запись в `src/core/data/levels.js`. Тест `levels.test.js` проверяет, что у неё есть решение и что она не решена с самого начала.

Новый пассажир — два кадра в `src/assets/art/` (`имя-sad.webp`, `имя-glad.webp`), запись в `passengers.js` и строка в `CREDITS.md`.

Новое желание — код в `WISH_CODES`, запись в `wishes.js`, ветка в `isWishMet` и иконка в `WishBubble.vue`.

## Правила игры

- Места 0–2 — верхний этаж под лампами, 3–5 — нижний. Места 2 и 5 — у дверей.
- Соседи — только на своём этаже.
- Первые пять станций заданы вручную, дальше расстановка перемешивается случайно.
